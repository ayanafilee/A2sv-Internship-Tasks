# 🚀 Job Board Platform

A modern platform for browsing job opportunities, featuring a clean interface and detailed job postings. Built with **React** and **Tailwind CSS**.


---

## ✨ Key Features

- **Dual View Interface**

  - 🗂 **Card-based list view** for quick scanning
  - 📄 **Comprehensive detail view** with full job description

- **Smart Data Handling**

  - 🔄 **API data transformation** layer
  - 🛡 **Type-safe props validation** with PropTypes
  - ⏳ **Loading states** and error handling

- **Enhanced UX**
  - 🔄 **Seamless view switching**
  - 📱 **Mobile-responsive design**
  - 🎭 **Interactive elements** with hover states

---

## 🛠 Tech Stack

- **Framework:** React
- **State Management:** Redux Toolkit (RTK Query)
- **Styling:** Tailwind CSS
- **Component System:** Functional Components
- **Data Validation:** PropTypes

## 🚀 Get Started

### 1️⃣ Clone Repository

```bash
git clone https://github.com/ayanafilee/A2sv-Internship-Tasks/tree/task7
cd Tasks7
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Start Development Server

```bash
npm start
```
### 3️⃣ Run Application

```bash
npm run dev
```
